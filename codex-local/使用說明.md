# Codex Conversation Exporter｜本機對話列印

適用你的 Mac 上 Codex 桌面版的本機對話記錄。直接讀取 `~/.codex/sessions`、封存記錄及唯讀的本機索引，不必分享連結、複製整段對話或安裝 Chrome 擴充功能。

## 開啟與列印

1. 將整個工具資料夾保留在一起。雙擊「啟動 Codex 對話列印.command」。需先安裝 Python 3.9 以上版本，無須 pip 安裝。
2. 工具會開啟本機網頁。啟動後的終端機視窗請先留著。
3. 左邊選擇要列印的 Codex 對話；可搜尋對話名稱或專案資料夾。
4. 預設選取提問與最終回答；取消不需要的訊息，也可選「只選 Codex 回答」。需要過程訊息時勾選「包含工作進度訊息」。
5. 按右上角「列印／另存 PDF」。Chrome 的目的地選「另存為 PDF」；Safari 在列印視窗的「PDF」選單選儲存 PDF。預設為 A4、12 pt。
6. 使用完畢，關閉啟動工具的終端機視窗，或按 Control+C 停止服務。

也可按「下載 Markdown」或「下載 JSON」。Markdown 保留文字、表格語法、LaTeX 與 Mermaid 原始碼；圖片以提示取代。JSON 包含選取的訊息和可取得的內嵌圖片，可作備份；目前不提供重新匯入 JSON 的介面。

若對話仍在產生新回答，等回答完成後重新選擇左側對話即可載入最新記錄。清單未更新時按「重新整理對話清單」。

## 介面語言

左上方 Language 選單可切換繁體中文、簡體中文、英文、日文或韓文。這會切換操作按鈕、狀態、文件標籤與列印提示；對話原文不會自動翻譯。語言偏好只放在本機網址，不使用 Cookie 或追蹤。

## 與瀏覽器擴充功能的差別

這個工具讀取 Codex 本機記錄。既有的 ChatGPT 瀏覽器擴充功能仍處理 ChatGPT 網頁，不能在原生 Codex 視窗內加入按鈕。本工具從啟動檔開啟，並不需要把 Codex 對話移到 ChatGPT 網頁。

## 排版與限制

- PDF 支援 Markdown、KaTeX 數學式及 Mermaid 流程圖，所有排版程式與字型均包在工具內。
- 表格只有淡色的橫向列分隔線，會依紙張寬度換行。
- 讀取本機記錄內的 PNG/JPEG/GIF/WebP 圖片及仍存在的本機圖片檔；不會為了圖片自動連線外部網站。SVG 程式碼、互動頁面、影片及外部網頁不等同於可擷取的圖片。
- 已刪除的臨時附圖、失效檔案及不支援內容會顯示警示。預設阻止缺圖內容直接列印；檢查後可勾選允許略過圖片。公式或流程圖排版失敗時會阻止列印，避免把錯誤當成完成品。無法保證還原記錄裡未保存的原生介面內容。
- 只列出本機有記錄的對話，不能讀取尚未同步到此 Mac 的雲端或其他電腦對話。記錄格式屬實作細節，Codex 更新可能需要相容性修正。
- 無登入、遙測或自動上傳。服務只綁定 127.0.0.1；每次啟動產生隨機存取碼。請勿將正在使用的本機網址或匯出檔分享給別人。

## 手動啟動與測試

```sh
python3 server.py
python3 -m unittest discover -s . -p 'test_*.py'
```

程式使用 Python 標準函式庫，無須 pip 安裝。網頁內附 markdown-it 15.0.3、Mermaid 12.2.0 及 KaTeX；各套件授權放在 `web/vendor/` 內。主程式採用上層專案的 MIT 授權。
